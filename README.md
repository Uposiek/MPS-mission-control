# MPS Mission Control

PWA dla iPhone'a z live telemetrią odliczania do odbioru Mazdy 3 MPS.

## GitHub Pages
1. Utwórz publiczne repozytorium, np. `mps-mission-control`.
2. Wgraj wszystkie pliki z paczki do głównego katalogu repozytorium.
3. Repo → Settings → Pages.
4. Build and deployment → Source: `Deploy from a branch`.
5. Branch: `main`, folder: `/ (root)` → Save.
6. Otwórz adres Pages w Safari na iPhonie.
7. Udostępnij → Dodaj do ekranu początkowego → „Otwórz jako aplikację”, jeśli opcja jest widoczna.
